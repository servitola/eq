### C1 — import architecture + full Equalizer APO grammar (first, on main)
- `Sources/eq/Import/Formats/` with `protocol EQFormat { static var name: String; static func sniff(_ data: Data, filename: String?) -> Bool; static func parse(_ data: Data) throws -> ImportResult }` and a registry tried in priority order; `AutoEqParser` becomes the APO format (keep `AutoEqParser.parse` as a thin wrapper for callers). `ImportResult` = today's `AutoEqParser.Result` (filters, bands?, preamp, format, warnings).
- Full APO: `Preamp:` (multiple → summed), `Filter N:`/`Filter:` with `ON|OFF`, all types (PK, PEQ, LP, LPQ, HP, HPQ, BP, NO, AP → skip+warn, LS/HS (fixed 12 dB/oct → Q 0.707), LSC/HSC with optional `x dB` slope → Q from slope, LS 6dB/12dB, LSQ/HSQ), `Fc` with `Hz`/`kHz`, `Gain`, `Q`, `BW Oct` → Q, `Channel:` (stereo-linked: take `L`/`all`/first block, warn when channels differ), `Include:` (resolve relative to the file path when importing from a file; refuse for URL/name imports; depth ≤ 4, no cycles), `GraphicEQ:` lines (existing path), `Device:`/`Copy:`/`Stage:`/`Eval:` ignored with one warning each. Decimal comma.
- AutoEq `FixedBandEQ.txt` detection → maps directly onto our 10 bands when its frequencies match ours (±1 %), else parametric peaks.
- REW / squig.link / peqdb text: same grammar variants (REW's `Filter  1: ON  PK       Fc   1000 Hz  Gain  -3.0 dB  Q  1.00` spacing, `Equaliser: …` header).
- Regression test for AutoEq's 0.1 dB preamp margin note in the research doc.
- Commit `Formats: a registry and the full Equalizer APO grammar`.

### C3 — export (worktree c-export, after C1)
`eq export [--format apo|graphiceq|eqmac|camilla|json] [--device DEVICE] [--out FILE]` (default apo to stdout). APO: `Preamp:` + one `Filter N:` per band (peaks at our centres, Q 1.41) + filters + preference shelves, with a header comment naming eq, device and date. GraphicEQ: AutoEq's 127-point grid computed from the full response (magnitudeDB sum at 48 kHz). eqMac: the Advanced 10-band JSON when the profile has no filters/preference, else Expert shape if we support it, else refuse with a message. CamillaDSP YAML: filters + pipeline snippet. `json`: our profile. Round-trip tests: export → import yields the same response within 0.1 dB at the band centres (apo, camilla, json exact; graphiceq within reduction tolerance).
Commit `eq export`.
