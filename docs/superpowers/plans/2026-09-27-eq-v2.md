# eq v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AutoEq import (exact, parametric), `--json` on every command, `eq doctor`, and a daemon that reports status from the first moment, does not churn on silence and recovers from a stalled IO path.

**Architecture:** Profiles gain an optional `filters` list rendered by the existing biquad engine alongside the ten graphic bands. The CLI grows a `Output` type carrying both text and an `Encodable` JSON value; `--json` selects the latter. Import is three small units: a content parser (vendored from OnlyEQ, trimmed), an AutoEq index client with an injected fetcher and a 7‑day cache, and the `import` command that wires them into the config store. `doctor` runs a fixed list of checks through injected probes. The daemon gets an IO-callback counter that drives verification and a watchdog.

**Tech Stack:** unchanged — Swift 5 mode, SwiftPM 5.10, macOS 14.4+, XCTest, zsh scripts.

Spec: `docs/superpowers/specs/2026-09-27-eq-v2-design.md` (deltas) on top of `docs/superpowers/specs/2026-09-27-eq-design.md`.

            guard let self else { return }
            if self.state == .running || self.state == .bypassed {
                let r = DaemonPolicy.stalled(previous: self.lastCallbacks, current: self.engine.callbacks, unchangedTicks: self.unchangedTicks)
                self.unchangedTicks = r.unchangedTicks

            }

            self.writeStatus()
        }

    static func run(_ args: [String], context: CLIContext) -> (exitCode: Int32, output: String) {
        let wantsJSON = args.contains("--json")
        let args = args.filter { $0 != "--json" }
        do {
            let output = try dispatch(args, context)
            return (0, wantsJSON ? encode(output.json) : output.text)
        } catch let error as CLIError {
            let code: Int32
            switch error {
            case .usage, .unknownBand, .badGain, .gainOutOfRange: code = 2
            default: code = 1
            }
            if wantsJSON { return (code, encode(ErrorReport(error: .init(code: error.code, message: "\(error)")))) }
            switch error {
            case .usage, .unknownBand, .badGain, .gainOutOfRange: return (code, "error: \(error)\n\(usage)")
            case .daemonNotRunning: return (code, "\(error)")
            default: return (code, "error: \(error)")
            }
        } catch {
            if wantsJSON { return (1, encode(ErrorReport(error: .init(code: "internal", message: "\(error)")))) }
            return (1, "error: \(error)")
        }
    }

    static func encode(_ value: Encodable) -> String {
        let encoder = JSONEncoder()
        encoder.dateEncodingStrategy = .iso8601
        encoder.outputFormatting = [.prettyPrinted, .sortedKeys]
        guard let data = try? encoder.encode(AnyEncodable(value)) else { return "{}" }
        return String(decoding: data, as: UTF8.self)
    }
