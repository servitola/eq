# eq v4 `eq watch` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A live per-band level display (`eq watch`) and a JSON stream (`eq stream`) fed by the daemon over a local socket, at zero cost while nobody watches.

**Architecture:** `BandMeter` (10 band-pass biquads + peak envelopes on mono input and mono output) runs inside `EQProcessor.process` behind one `Bool`; `MeterServer` owns a Unix socket next to `status.json`, counts clients, and while `clients > 0` ticks at 30 Hz, snapshots the meter into a `MeterFrame`, and writes one JSON line per client. `MeterClient` in the CLI connects and yields lines; `Watch.frame` is a pure renderer; `eq watch` drives the terminal.

**Tech Stack:** unchanged; POSIX sockets via `Darwin` (`socket/bind/listen/accept`, `DispatchSource.makeReadSource`), `termios` for `q`.

Spec: `docs/superpowers/specs/2026-09-27-eq-v4-watch.md`.

## Global Constraints

- Repo `/Volumes/SanDisk/projects/eq`, `main`, origin gitea; never push from a task. 117 tests at the start.
- Audio thread: no allocation, lock or logging; the meter runs only when `meteringEnabled` is true; all buffers pre-sized in `init`.
- Band centres `Config.bandFrequencies`, band-pass Q 1.41; envelope attack 10 ms, release 300 ms; dB floor −60; `MeterFrame.in/out` are 10 `Double`s rounded to 0.1.
- Socket path: `Status.defaultURL.deletingLastPathComponent()/meter.sock` (`EQ_STATUS` decides the directory); removed at start if stale and on exit.
- Tick 30 Hz only while `clients > 0`; log `meter: N client(s)` on every change.
- `eq stream` is JSON lines only; `eq watch` needs a TTY ≥ 64×16; both exit 1 with `CLIError.daemonNotRunning` when the socket is missing/refused (message adds "or predates v4").
- Comments only "why"; no TODOs.

**Files:** `Sources/eq/Engine/BandMeter.swift` (new), `Sources/eq/Engine/EQProcessor.swift`, `Sources/eq/Engine/BiquadFilter.swift` (band-pass already exists as `FilterType.bandPass`); test `Tests/eqTests/BandMeterTests.swift`.

**Interfaces:**
```swift
final class BandMeter {
    init(frequencies: [Double])                       // pre-allocates everything
    func configure(sampleRate: Double)                // rebuilds coefficients and envelope constants
    /// Audio thread. `input`/`output` are the deinterleaved stereo channels; mono = 0.5*(L+R).
    func feed(input: [UnsafeMutablePointer<Float>], output: [UnsafeMutablePointer<Float>], frameCount: Int)
    func reset()
    /// Any thread (racy reads are fine): current envelopes in dBFS, −60 floor.
    var inputDB: [Double]; var outputDB: [Double]; var peakDB: Double
}
```
`EQProcessor`: `let meter = BandMeter(frequencies: Config.bandFrequencies)`; `var meteringEnabled = false` (plain Bool, written on main, read on the audio thread); in `process`, **before** the chain copy the mono input into a pre-allocated scratch (max 4096 frames; if `frameCount` exceeds it, skip metering this callback), run the chain as today, then if `meteringEnabled` call `meter.feed(...)` with the input scratch and the processed channels; also expose `var limiting: Bool` (true when the limiter reduced gain in the last callback). `configure(sampleRate:)` forwards to the meter.

### Task 4: `eq watch`

**Files:** `Sources/eq/CLI/Watch.swift` (renderer + terminal loop), `Sources/eq/CLI/CLI.swift`; test `Tests/eqTests/WatchTests.swift`.

**Interfaces:**
```swift
enum Watch {
    static let minColumns = 64, minRows = 16, meterRows = 12
    static func frame(_ f: MeterFrame, rows: Int = meterRows) -> [String]   // header, meter rows (top→bottom), labels row, gains row
    static func run(client: MeterClient, out: FileHandle, isTTY: Bool, size: () -> (cols: Int, rows: Int)) -> Int32
}
```
Renderer rules (spec "What the user sees"): row index `r` from top (0) to `rows-1`; a level `L` dB fills rows where `rowLevel(r) <= L`, `rowLevel(r) = -60 + 60 * (rows-1-r)/(rows-1)`; output block `█` in `Paint.gain(gains[i])` ink; input `░` dim where input reaches but output does not; the gain marker `▬` at `r = round((12 - gain)/24 * (rows-1))` replaces the cell; header `"<device> · <rate/1000 with one decimal> kHz · preamp <±x.x> dB"` padded, then `LIMIT` in yellow when `limiting`; footer = the two rows `Table` prints (reuse `Table`'s label/gain formatting; no spark row). Column width 6, 10 columns, 2-space left margin (matches `Table`).
Terminal loop: enter alternate screen `\u{1B}[?1049h`, hide cursor `\u{1B}[?25l`, `tcsetattr` non-canonical no-echo; on each frame move home `\u{1B}[H` and write the joined rows with `\u{1B}[K` line clears; poll stdin with `poll()` for `q`; SIGINT/SIGTERM and normal exit restore (`\u{1B}[?25h\u{1B}[?1049l`, original termios). Refuse when `!isTTY` or size below minimum with `CLIError.usage("eq watch needs a terminal of at least 64×16")`.

### Task 6 (v4.1): adaptive layout, live row, shades, fractional tops

**Files:** `Sources/eq/CLI/Watch.swift`, `Sources/eq/CLI/Paint.swift` (bright inks), `Sources/eq/CLI/Table.swift` (parametrised width/short labels); tests `WatchTests`, `PaintTests`.

**Interfaces:**
```swift
struct WatchLayout: Equatable { var columns: Int; var cellWidth: Int; var meterRows: Int; var shortLabels: Bool
    static func fit(cols: Int, rows: Int) -> WatchLayout }   // per the v4.1 spec
enum Paint.Ink { … case brightGreen = 92, brightMagenta = 95, brightYellow = 93 … }
static func Paint.level(_ ink: Ink, hot: Bool) -> Ink       // normal → bright when hot
static func Watch.frame(_ f: MeterFrame, layout: WatchLayout) -> [String]  // header, meterRows, live row, labels, gains
```
- `fit`: `cellWidth = clamp((cols-2)/10, 3, 8)`; `columns = min(10, max(1, (cols-2)/cellWidth))`; `meterRows = max(4, rows - 5)`; `shortLabels = cellWidth < 6`.
- Bar cell at row r for band i: level `L = out[i]`; `top = (L + 60) / 60 * meterRows` (in rows, fractional); full rows below `floor(top)` get `█`; the row at `floor(top)` gets the partial glyph for `frac(top)` (index `Int(frac*8)` into `▁▂▃▄▅▆▇█`, 0 → space); input `░` where `in` reaches above the output's top row; marker row from gain as today (clamped/finite). Ink: `Paint.level(Paint.gain(gain), hot: L >= -6)` for `█` and the partial; marker ink `Paint.level(Paint.gain(gain), hot: abs(gain) > 6)`.
- Live row: `String(format: "%*.0f", cellWidth, L)` or `·` right-aligned when `L <= -59.5`, inked like the bar.
- Header: `"<device> · <rate> kHz · preamp <±x.x> dB · peak <±x.x> dB"` + `LIMIT` yellow/`BYPASS`; truncated to `cols` (drop segments from the right until it fits).
- Short labels: `["32","64","125","250","500","1k","2k","4k","8k","16k"]`; `Table.labelsRow(width:short:)` and `gainsRow(_:width:)` gain parameters with defaults preserving today's output.
- Fewer than 10 columns: draw the first `columns` bands and append a dim line `… widen for all bands` under the gains row.
- Tests: `fit` cases (200×50 → 8/10/45/full; 64×16 → 6/10/11/full; 40×12 → 3/10/7/short; 24×10 → 3/7/5/short); frame row counts for a layout; partial glyph for `out = -30` at 12 rows (top = 6.0 → row 6 full, no partial) and `-27` (top 6.6 → partial `▅` at the row above); live row shows `-27`; hot ink used for `-3`; header truncation at 40 cols keeps device and drops peak.
