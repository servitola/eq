### B1 — hand-edited parametric filters (worktree b-model)
`eq filter` (list, default), `eq filter add <type> <freq> <gain> [q] [--device DEVICE]` (types: peak lowshelf highshelf lowpass highpass notch bandpass; freq `1k`/`1000hz`/`1000`; gain `+3`/`-2.5`; q default 0.707 for shelves/passes, 1.41 for peak), `eq filter set <n> [freq=…] [gain=…] [q=…] [type=…]`, `eq filter rm <n>|all`, numbering 1-based as shown by `eq`. Validation via existing `Config.validate` (ranges, 32 cap, stability). Hand edits keep `imported` untouched but mark the profile `modified`-style? — no: imported filters and hand filters share one list; `eq` shows a `source` column (`import`/`hand`) → `Filter.origin: String?` (`"import"` set by `eq import`, nil = hand; decodeIfPresent). `eq import --clear` removes only `origin == "import"` filters (keep hand ones) — change and document. Tests.

### B2 — preference layer: bass, treble, tilt (same worktree, after B1)
`Profile.preference: Preference? { bass: Double, treble: Double, tilt: Double }` (dB; bass = low shelf 105 Hz Q 0.7, treble = high shelf 10 kHz Q 0.7, tilt = ±dB across 20 Hz–20 kHz implemented as a low shelf −tilt/2 at 1 kHz + high shelf +tilt/2 at 1 kHz with Q 0.5 — pick from AutoEq's defaults as documented in 03-headphone-data.md; ranges ±12). `eq bass +3`, `eq treble -2`, `eq tilt -1`, each `--device`; `eq` shows a `preference` line when non-zero. `engineBands` appends the preference shelves after bands+filters. In `eq watch`: `b`/`B` bass ±0.5, `t`/`T` treble ±0.5 (Russian `и`/`И`, `е`/`Е`), header shows `bass +3 treble -2` when set. Presets carry the preference (it is part of the profile). Tests incl. magnitude checks via `BiquadCoefficients.magnitudeDB`.

### B3 — smarter AutoEq search (worktree b-import)
Variant tags parsed from names (`(ANC On)`, `(ANC Off)`, `(transparency mode)`, `(sample 2)` …) → `eq import "airpods pro 2" --variant anc-on` and, without `--variant`, prefer the variant without a tag, else `ANC On`, else ask. Fuzzy matching: normalise (case, punctuation, spaces, `-`), token prefix match, Levenshtein ≤ 2 on the model token; show "did you mean" for no match. Aliases for common spellings (`wh1000xm4` → `WH-1000XM4`, `airpods pro2`). `eq import --search <query>` lists matches with source and variant (text + `--json`) without importing. Tests on the fixture index extended with variant lines.
