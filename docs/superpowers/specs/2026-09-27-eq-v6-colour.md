# eq v6 — colour everywhere

Date: 2026-09-27. Status: requested in chat ("всё ладненько, мило, классно"). Rules are the
existing ones (v2 "Colour in the terminal"): sixteen terminal colours plus their bright
variants, one meaning each, only on a TTY, `NO_COLOR` / `TERM=dumb` / pipes stay plain.

## `eq --help`, `eq help`, usage after an error

- Grouped, with dim headings: **look** (`eq`, `devices`, `status`, `watch`, `zones`,
  `stream`), **tune** (`set`, `preamp`, `flat`, `copy`, `preset …`, `import …`, `undo`,
  `on`, `off`), **setup** (`init`, `doctor`, `daemon`).
- Command words bold; flags (`--device`, `--json`) cyan; placeholders (`<band>`, `<gain>`,
  `<name>`, `DEVICE`) yellow; descriptions plain; examples dim.
- Two columns: the invocation and the description. The description column starts at a
  shared offset and **wraps inside its column** at the terminal width (never mid-word, never
  back to column 0). Below 60 columns: one-column layout, description on the next line
  indented by 4.
- The device placeholder is renamed from `Q` to `DEVICE` everywhere (it collided with filter
  Q). Bands and gains footer lines stay, painted.
- `eq <command> --help` prints only that command's block plus its examples.
- After a usage error: `error:` red, the message plain, then a blank line and **only the
  relevant command's block** (not the whole usage).

## `--json` on a terminal

Pretty, coloured like `jq`: keys blue, strings green, numbers yellow, `true`/`false` cyan,
`null` dim, braces/brackets/commas/colons dim. Indentation 2 spaces. Piped or `NO_COLOR`:
exactly today's output byte for byte (sorted keys, pretty, `/` unescaped). `eq stream`
lines stay compact and uncoloured even on a TTY (it is a data stream).

## Everything else

`init`, `on`/`off`, `copy`, `import` summaries, `preset` list/show/save/use, `undo`
(+ `--list`), `devices`, `status`, `doctor`, `zones`, error lines everywhere: one pass so
every human-facing line follows the rules — names bold, numbers by meaning (gains by sign,
levels by heat), paths dim, success green, warnings yellow, errors red. No emoji.
